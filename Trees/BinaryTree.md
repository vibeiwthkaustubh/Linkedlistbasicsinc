 A TREE IS USEFUL FOR REPRESENTING THE HIERARCHIAL DATA.

Binary tree is a tree where every node is will either be equal to 2 or be less that 2 
(0 >=degree<=2)

Binary tree is tree which has at most 2 children for all its nodes.(It can be 1 or 0)

A tree is made up of nodes and edges    (N nodes in a tree means n-1 edges.)

Degree can be :- (0 >=degree<=2)  // Tree of degree 2 is called the binary tree.

Degree of a node can be said the number of outgoing edges/children that node have and degree of a node is the property of the node itself.

Degree of a tree can be said as the maximum number of edges found among all the nodes in that entire tree.

->TYPES OF THE BINARY TREE ARE THERE 
      
1. FULL OR STRICT BINARY TREE
---> All the node will have either 0 or 2 children.

2. PERFECT BINARY TREE 
---> All INTERNAL NODES  have exactlty 2 nodes and + All  LEAF NODES  are on the same level.

3. COMPLETE BINARY TREE 
--->  Every level is completely filled , except possibly the last (bottom) level.
-----> On the last level , all nodes are packed as far as possible with no gaps between them 
-----> (think of a movie theater filling the seats row by row from the left).
-----> And why is it necessary, so we can store the whole tree inside the single array without wasting any memory location.

4. DEGENERATE TREE 
---> Every parent node has exactly one child
