The Binary Search Tree is a type of Binary Tree only.

There are some rules that every node of the tree must follow to become a binary search tree.
1. Every value in the left subtree must be smaller than the root.
2. Every value in the right subtree must be greater than the root.
3. No duplicate nodes (same values exist but not left right of the same node) are allowed as it will contradict the first 2 rules.
4. InOrder traversal of a BST always gives an ascending sorted array.
